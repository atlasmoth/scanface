LIGHT MOBILE PROMPT
Use case: ui-mockup.
Create a polished, original, implementation-ready visual design board for ScanFace, a private on-device facial-age estimation mobile app. This is an actual app UI proposal, not a marketing website. LIGHT MODE. Render at high resolution, approximately 2560 x 1600, landscape. Extremely crisp readable typography, precise spacing, high-end editorial product design.
Composition: exactly four flat front-facing mobile app viewports, equal height and width, aligned horizontally, with slim dark outlines and subtly rounded outer corners, no tilted phones, no perspective, no hands, no floating UI. Each viewport has a realistic 390x844 logical proportion. Generous gutters. Quiet warm gray presentation background. Small board header above: "ScanFace" and "01 / Mobile · Light". Small external captions below each viewport: "Overview", "Capture", "Result", "History".
Design system: warm ivory #F6F7F2 app background, white #FFFFFF cards, pale sage #E5EDE6 inset surfaces, deep ink #16251F text, readable slate-green #59695F secondary text, forest green #245C45 primary actions with white labels, hairline #D9E1D9 borders. Use a single refined SF Pro / Inter-like sans serif. Large tabular numerals, understated headings, minimal 1.5px line icons, 8px spacing rhythm, 24px page padding, 20px card radii, 14px button radii. No gradients or glossy glass effects. Main UI text high contrast and large enough to read. Brand symbol is a very simple open oval face frame with two small registration marks.
Navigation: bottom navigation on Overview, Result, History consists of exactly "Overview", "Scan", "History" with simple icons, active item on a pale sage pill. Capture is a focused full-screen flow without tab navigation.
